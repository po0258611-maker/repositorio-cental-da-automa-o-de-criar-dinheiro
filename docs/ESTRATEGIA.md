# 💡 Estratégias Validadas para 2024-2026

## Estratégia 1: Afiliado Shopee Vídeo Viral (R$ 50-150/dia)
1. Use `automacoes/scraping` para achar produto com desconto >40% e vendas >2000/mês
2. Gere vídeo com `conteudo-ia`: prompt "unboxing + prova"
3. Poste no TikTok Shop / Kwai com link de afiliado Shopee
4. Comissão Shopee afiliado: 10-20%

## Estratégia 2: Hotmart + Instagram Dark
1. Garimpo: produto de R$ 97 com comissão 70% = R$ 67 por venda
2. Crie Instagram dark (sem rosto) no nicho do produto
3. 2 Reels/dia com roteiros da IA + 1 carrossel
4. Link na bio com checkout direto
5. Meta: 3 vendas/dia = R$ 200/dia = R$ 6k/mês

## Estratégia 3: Bot que Recupera Vendas
- 70% das pessoas clicam e não compram
- Bot manda em 15min: "Olá, vi que se interessou por X, ainda quer o desconto?"
- Recupera 15-25% das vendas perdidas
